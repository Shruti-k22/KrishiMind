CROP PICTURES
=============

One JPEG per crop, named after the crop in lowercase English:

    sugarcane.jpg     grapes.jpg      pomegranate.jpg
    soybean.jpg       jowar.jpg       onion.jpg
    gram.jpg          wheat.jpg       cotton.jpg
    tur.jpg           bajra.jpg       rice.jpg
    mango.jpg         orange.jpg      mosambi.jpg
    banana.jpg        cashew.jpg      coconut.jpg
    jackfruit.jpg     betel_nut.jpg   turmeric.jpg

Already here: sugarcane, pomegranate, wheat, onion, rice, jowar.
Still needed:  grapes, soybean, gram (and the rest, over time).

Rules:
  * Roughly square. 360x360 is plenty — the tile is only about 104x62 on
    screen, so anything bigger is wasted app size and wasted memory.
  * The crop clearly visible and filling the frame.
  * NO WATERMARKS, and no paid stock (Adobe Stock, Shutterstock, Vecteezy,
    pngtree, Freepik). This repository is public and the project is being
    submitted to a college, so a licensed image is a real problem.

Safe sources: pixabay.com, pexels.com, openclipart.org, Wikimedia Commons —
or photograph the crops yourself, which is better than any of them.

Any crop with no file here falls back to a drawn illustration automatically.
